# FBA 物流查询开发项目

当前支持安达、超鸿和易通查询，自动识别货代并提示多货代冲突；查询成功后可将发生变化的最新路由自动写入 WPS 共享表的 `US-FBA` 子表。

易通使用官网后台接口查询。首次登录或会话失效时，程序会显示官网图形验证码，需人工输入一次；有效会话会加密保存并在下次启动时自动验证，不识别或绕过验证码。

## 启动方式

当前项目保持正常源码开发形式，不生成 EXE。项目的全部 Python 依赖保存在自己的 `.venv` 中，不使用全局 Python 环境。安装完成后可以双击 `启动项目.bat`，也可以执行：

```powershell
.\.venv\Scripts\python.exe main.py
```

如果 `.venv` 不存在，运行：

```powershell
.\setup_project.ps1
```

## 在多台电脑继续开发

源码通过私有或公开 Git 仓库同步，但每台电脑都应保留自己的运行环境和本机数据库。

切换电脑时：

1. 离开当前电脑前提交并推送源码。
2. 在另一台电脑开始开发前先拉取最新源码。
3. 不要把 `.venv`、`data/app.db`、`packages` 或根目录 EXE 提交到 Git。
4. 新电脑首次使用时重新录入货代密码、WPS APPKEY并完成一次WPS授权。

`data/app.db` 中的密文使用当前 Windows 用户的 DPAPI 保护，不能假定复制到另一台电脑后仍可解密。WPS 本机回调地址仍可使用 `http://127.0.0.1:8765/wps/callback`，无需为每台电脑分别创建应用。

## 慢网络和离线安装

在网络好的 Windows 电脑上先运行：

```powershell
.\准备离线依赖.ps1
```

依赖安装包会保存到项目内的 `packages\wheels`。该目录不会上传到 Git，可以使用U盘或移动硬盘复制到另一台电脑的同一项目目录。

新电脑安装好64位 Python 3.12后，在不联网的情况下运行：

```powershell
.\离线安装项目.ps1
```

脚本会在项目内部创建 `.venv`、从本地安装运行和测试依赖，并自动运行测试。离线包与生成它的 Python 版本及 Windows 架构有关；两台电脑建议都使用64位 Python 3.12。

## 数据库

数据库固定为 `data/app.db`。安达、易通密码、易通会话令牌、WPS APPKEY 及 WPS 授权令牌均使用 Windows DPAPI 加密后写入数据库，不保存明文。

请勿删除 `data` 目录。数据库密文与当前 Windows 用户和电脑绑定，换电脑后需要重新录入一次密码。

## 易通首次使用

1. 启动程序，在“易通账号”区域输入自己的账号和密码。
2. 等待验证码图片出现，输入图片内容。
3. 点击“安全保存并登录”。
4. 登录成功后直接粘贴 FBA 查询；以后会优先复用加密会话，会话失效才需再次输入验证码。

如果验证码看不清或失效，点击“刷新验证码”。

## WPS 共享表首次连接

当前版本只处理美国站点，程序会按名称查找 `US-FBA` 子表，不依赖它在工作簿中的位置，也不写入其他国家子表。

1. 在 WPS 开放平台的企业自建应用中启用用户权限 `kso.sheets.readwrite` 和 `kso.file.read`。
2. 将本机回调地址设为 `http://127.0.0.1:8765/wps/callback`，并保持接口签名关闭。
3. 启动程序，在“WPS 共享表”区域填写 APPID、APPKEY、共享链接，以及 `US-FBA` 中FBA和路由所在的 Excel 列字母（例如 A、I）。列字母只需首次填写，表头文字可以是 `FBA`、`FBA号`、`路由` 或其他名称。
4. 点击“安全保存并连接 WPS”，在浏览器中用有该文件编辑权限的 WPS 账号完成授权。
5. 程序会验证文件、定位唯一的 `US-FBA` 子表，并检查所填列是否处于工作表使用范围内。显示“已连接”后即可查询物流。

WPS 传统 `.xlsx` 的“查找选区”接口会把第一行作为字段定义并排除在结果之外，因此服务端无法可靠读回第一行文本来自动识别列名。当前免费企业权限下，文件下载接口也不可用，所以不能安全地根据表头自动选列。程序不会猜测并写入可能错误的列。列字母只需首次填写；如果以后移动了这两列，在程序中同步修改列字母并点击“重新验证共享表”即可，不需要重新创建应用。

程序会在每次同步前重新读取 `US-FBA` 的最新使用范围，因此连接WPS后继续新增FBA行，也不会因为沿用旧范围而漏掉尾部数据。

APPKEY、访问令牌和刷新令牌会使用 Windows DPAPI 加密后保存到 `data/app.db`，不会以明文写入代码、配置或日志。共享链接和 APPID 不是密码，会直接保存在数据库中。

查询完成后的自动回填规则：

- 只处理查询状态为“成功”且有最新路由的 FBA；冲突、失败和未找到结果不会写入。
- 根据已保存的列字母定位 FBA 和路由列；列顺序调整后需同步修改这两个设置。
- 仅写入 `货代最新路由信息`，不会修改“是否完成”等其他列，也不会修改单元格格式。
- 表内旧值与新值完全相同时不发起写入。
- FBA 在表中不存在时跳过；同一 FBA 出现多行时停止该 FBA 的写入并提示重复，避免写错行。

换到公司的电脑运行时，项目文件可以整体复制，但由于 DPAPI 密文与当前 Windows 用户和电脑绑定，需要在新电脑重新填写货代密码、WPS APPKEY 并完成一次 WPS 授权。若仍使用同一回调地址且开放平台设置未变，不需要重新创建应用。
