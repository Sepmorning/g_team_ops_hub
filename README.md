# FBA运营工作台（网页版）

这是当前持续开发的FastAPI网页版项目。桌面验证版已经分离到同级目录 `D:\CodexProject\FBA_Tracker_Desktop`，两套程序拥有独立源码、依赖、数据库和EXE，互不读写对方的数据。

## 从GitHub全新安装（Windows）

仓库不包含任何人的系统账号、货代密码、易通会话、店铺链接或AirScript令牌。
每台电脑首次运行都会在自己的 `data` 目录创建独立配置。

```powershell
git clone https://github.com/Sepmorning/FBA_Tracker.git
cd FBA_Tracker
.\setup_project.ps1
.\start_web.ps1
```

也可以在Windows中直接运行仓库根目录的 `FbaTrackerWeb.exe`。源码开发建议使用
64位Python 3.11或3.12；安装脚本会在项目内创建 `.venv`，不会修改项目代码。

首次使用按以下顺序配置：

1. 浏览器打开 `http://127.0.0.1:8765`，在 `/setup` 创建这台电脑自己的系统管理员。
2. 进入“货代连接”，填写自己的安达账号；易通填写自己的账号密码并输入验证码。超鸿无需账号。
3. 按 `AirScript升级说明.md` 在自己的WPS工作簿安装版本10物流脚本；按需准备各国家的 `代码-FBA` 和 `代码-轨迹明细`。
4. 如需库存销售更新，按 `库存销售表格模块使用说明.md` 准备表头、公式和版本3 Listing AirScript。
5. 进入“我的店铺”，先保存店铺名称和共享表链接，再分别连接物流与Listing脚本，点击“扫描共享表”并核对国家站点。
6. 进入“物流查询”或“库存销售表格”，只选择店铺和国家站点后执行任务。

`data/`、`.venv/`、日志、密码、会话和令牌都已被Git忽略。不要强制添加这些
本机文件；复制仓库也不会复制原电脑的DPAPI密文。

## 已实现功能

- 管理员初始化、普通用户创建、停用和密码重置
- 用户货代账号、登录会话和店铺配置严格按用户隔离
- 安达、超鸿、易通查询与货代冲突检测
- 多店铺WPS AirScript配置
- 手动FBA查询并可选回填
- 从 `US-FBA` 自动读取未完成FBA及货代，优先按指定货代分批查询；仅对明确“未找到”的号码查询其他货代兜底，再统一回填
- 统一解析三家货代完整轨迹，将当前快照写入主表，并把预计、实际、变更、异常、恢复和POD逐事件追加到 `US-轨迹明细`；同步后清理已经不活跃货件的明细行
- 主表和明细表按表头名称自动识别列，列顺序任意，店铺、备注等自定义列不受影响
- 主表本次真实更新单元格使用“矢车菊蓝，着色1，浅色80%”标记，网页同步列出单元格地址、表头及新旧值；轨迹明细表不着色
- 官网最新轨迹未变化时复用本机详情缓存，减少详情请求和重复明细写入
- 本地滚动日志，不记录密码、令牌或请求正文
- 进入物流查询页面时后台自动登录并检查三家货代；每次点击手动查询时再次实时检查
- 进入货代连接页面时不自动检查或登录；会展示当前用户最近 10 分钟内的实时检查结果，超时、程序重启或凭据变更后恢复为“未检查”
- 保存或删除某一家货代账号时只更新该货代的状态，其他货代最近检查结果继续保留
- 某家未连接不会终止手动查询；本次只调度检查成功的货代，其他货代仍可正常返回和回填
- 安达查询复用同次实时检查建立的短时内存会话，避免检查后重复登录
- 安达、易通账号密码使用DPAPI保存；易通会话失效时自动加载已保存凭据，用户只需重新输入验证码
- 领星Listing导出文件按表头名称识别，选择店铺和国家后预览并更新对应Listing子表
- FBA可售、预留、在途按领星库存字段聚合；本次/上次数据按日期安全滚动
- “优惠价”为双端可选字段；领星文件与共享表都有该表头时才同步，领星空值会清除旧优惠价

## 运行

直接运行：

```text
FbaTrackerWeb.exe
```

浏览器访问 `http://127.0.0.1:8765`。关闭EXE窗口会停止本机服务。

源码运行：

```powershell
.\setup_project.ps1
.\start_web.ps1
```

项目依赖全部安装在本目录的 `.venv` 中。本机业务数据位于 `data`，不会提交到版本库。

## 数据和安全

- 登录密码使用不可逆PBKDF2哈希。
- 货代密码、登录令牌和AirScript令牌使用当前Windows用户的DPAPI加密。
- 管理员可以管理系统账号，但不能查看其他用户的业务密码或令牌明文。
- 当前用户可在自己的货代连接页面查看已保存账号；密码默认遮挡，主动点击小眼睛后才显示。
- 货代账号输入框会阻止浏览器登录密码自动填充，优先恢复本机加密保存的安达、易通账号密码。
- 每个店铺、货代配置和会话查询都必须带当前登录用户的 `profile_id`。
- `data` 目录只应保存在当前电脑；不要提交或发送给他人。
- 易通和超鸿当前上游业务接口仅提供HTTP；易通登录请只在可信公司网络使用，避免公共Wi-Fi。项目不会关闭证书校验来伪装HTTPS安全。

## AirScript

物流正式脚本为 `airscripts\FBA物流自动回填.js`。升级和必需表头见 `AirScript升级说明.md`。
Listing使用独立脚本 `airscripts\Listing库存销售自动回填.js`，最终表头、Excel/WPS公式和启用步骤见
`库存销售表格模块使用说明.md`。两个脚本使用不同Webhook和令牌。

物流脚本结构版本为10，Listing脚本结构版本为3。两个脚本都支持只读扫描当前
工作簿的全部子表；物流脚本由网页明确传入所选站点的FBA主表和轨迹明细表，
不再固定为美国。两张物流表仍按第一行表头名称定位列，不依赖列字母；
标准表头可以与店铺、备注等业务列混排。Listing源文件和共享表同样按表头名称
动态定位，`优惠价`可位于任意列；程序不会重排共享表列或改写Excel/WPS公式。

“我的店铺”是唯一长期配置入口：先保存店铺名称和共享表链接，再分别连接物流、
Listing脚本，最后点击“扫描共享表”识别 `店铺-国家`、`国家代码-FBA`、
`国家代码-轨迹明细`。库存销售和物流查询页面只选择店铺与国家站点，不再重复
输入共享表、Webhook或令牌。自动扫描只保存本机映射，不修改WPS内容；`UK-FAB`
等疑似拼写错误只提示，不会被自动当成FBA主表。店铺显示名称与Listing子表前缀
分开保存：首次扫描检测到唯一前缀时由用户确认一次并永久保存，后续扫描严格使用
已确认前缀；存在多个前缀时必须人工选择。“重新识别前缀”不会在用户确认前覆盖
原有设置。

自动回填不再维护 `运输方式`、`运输线路/渠道`、`目的仓`、`末端追踪号`，
这些字段可由用户或其他模块独立维护。新版AirScript还会统一日期显示格式，
并将货代订单号按文本写入，避免Excel日期序号和科学计数法。

任务总量不限制为50条。程序只在内部按最多50条分批查询和回填，以降低货代接口和WPS服务压力。

店铺“一键查询并更新物流”严格只读取主表中 `是否完成` 为空的FBA；该列只要有任何内容（包括“是”或“否”）就完全跳过，不再根据 `物流最后更新时间` 决定是否补查。手动输入FBA查询不受此规则限制。

店铺一键任务会读取共享表“货代”列：单元格包含“安达”“超鸿”或“易通”
时，优先查询对应货代；只有指定货代明确返回“未找到”，才查询另外两家兜底。
查询失败不会触发兜底。兜底时若一家命中而另一家查询失败，将标记为“部分查询失败”
并跳过回填，避免尚未排除货代冲突就写入错误数据；系统也不会自动改写“货代”列。手动输入查询仍会查询
本次实时检查成功的货代，以保留货代冲突检测。

一键任务会分别维护预计出发、实际出发、预计到达、实际到达、预计送达等字段。
提货、实际出发、实际到达和签收时间已有人工值时不会被不同的官网解析值覆盖；
冲突会在任务结果中提示。“提取派送”表示最近一次实际开始派送的日期，发现重新
派送时会更新为新的日期。完整轨迹以稳定事件编号去重，新的官网事件只追加一次，
计划失效状态可在已有明细行上更新。新明细始终追加在明细表末尾，并按主表FBA行号、
同一FBA轨迹时间依次排列。同步完成后，明细表只删除主表中“是否完成”非空或已从
主表移除的有效FBA行；仍为空的活跃FBA即使本次查询失败也保留原有明细，空白、
说明和无效FBA行不会自动删除。
轨迹明细中的日期时间会先统一为同一口径再比较，避免WPS的Excel日期序号与文本日期被误判为变化；任务结果中的“新增、实际更新、无变化”互不重叠。

每次成功查询并在主表唯一匹配FBA后，脚本只清除物流标准字段中由系统留下的旧蓝色，
再给本次真实写入成功的业务单元格设置“矢车菊蓝，着色1，浅色80%”。
`物流最后更新时间`仍会刷新，但不标蓝、不计入业务更新；轨迹明细表始终不进行颜色处理。
网页会在“本次共享表更新明细”中展示单元格地址、表头和新旧值，颜色格式失败只作为警告，
不会把已经成功写入的数据判为失败。

## API命名

- `/api/tracking/query`：手动物流查询
- `GET /api/carriers/status`：读取本机配置和最近检查状态
- `POST /api/carriers/validation`：实时登录并验证货代连接
- `/api/carriers/anda`：安达账号
- `/api/carriers/yitong/captcha-challenges`：易通验证码
- `/api/carriers/yitong/session`：易通登录会话
- `/api/shops`：店铺
- `/api/shops/{shop_id}/config`：店铺模块连接与国家站点
- `/api/shops/{shop_id}/logistics-connection`：物流脚本连接
- `/api/shops/{shop_id}/listing-connection`：Listing脚本连接
- `/api/shops/{shop_id}/discover-sites`：只读扫描并保存明确站点映射
- `/api/shops/{shop_id}/sites`：手工维护国家站点三子表映射
- `/api/shops/{shop_id}/validation`：验证店铺AirScript
- `/api/shops/{shop_id}/tracking-sync`：按请求中的国家站点一键查询并回填

旧的 `/api/connections/*`、`/api/query` 和单配置AirScript接口已经移除。

本轮发现、修复和保留风险详见 `项目代码审计报告.md`。
